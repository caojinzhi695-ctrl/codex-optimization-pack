# 安装、验证与回滚

先核对当前官方文档；不要整份覆盖个人配置。

## Windows 安装
1. 用户 Skill 默认目录为 %USERPROFILE%\.agents\skills\。将本仓库 skills/reuse-first、skills/github-project-delivery 两个文件夹复制进去；也可只安装需要的一个。同名目录已存在时先备份并比较。
2. Codex 用户目录默认为 %USERPROFILE%\.codex；如设置了 CODEX_HOME，则使用实际目录。先备份已有 AGENTS.md。
3. 合并 templates/AGENTS.md 中与已安装 Skill 对应的规则区块（reuse-first 和 github-project-delivery）。若存在 AGENTS.override.md，它优先于 AGENTS.md，需要检查当前有效文件并合并，避免新增无效规则。
4. 新开会话或重启应用刷新技能。不要替换 config.toml、auth.json 或改变模型、登录与权限。

## 验证
- 新会话要求列出已收到的项目复用与 GitHub 交付规则，检查是否发现已安装的 Skill。
- 示例：“我要一个 Windows 本地 Markdown 博客工具，免费离线生成、不需要数据库。仅比较两个候选并保存调查，不安装。”
- 小改：“只把某按钮文字颜色由 red 改为 blue。”应直接改并做必要检查，不重新搜索 GitHub。
- 查询一项官方文档，实际调用需要的工具；不要仅以配置文件存在来判断服务已连接。

## 回滚
从有效全局指令文件中移除对应的 reuse-first 或 github-project-delivery 起止标记区块；将本次安装的同名 Skill 文件夹移到用户 Skills 搜索目录之外，再新开会话。保留原有规则与其他 Skills。后续已修改同名 Skill 时，先比较再回滚。
