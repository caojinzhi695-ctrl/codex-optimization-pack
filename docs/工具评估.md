# 工具评估（2026-10-16）

本机已有网页搜索、Git、rg、Node 与浏览器控制，优先复用。

| 工具 | 本次决定 | 原因 |
| --- | --- | --- |
| GitHub 官方 MCP | 不新增 | 公开仓库网页检索足够；私有仓库或批量 Issues 需求出现时，再考虑只读及最小白名单 |
| Context7 | 不新增 | 本次不需要库接口查询；实际核实版本 API 时再评估，OpenAI/Codex 配置优先官方文档 |
| Playwright CLI + Skills / MCP | 不新增 | 已有浏览器完成连通性验证。需要自动化测试时优先评估 CLI + Skills；持久交互场景再考虑 MCP，只选一套 |
| Serena | 不新增 | 当前无大型代码库，文件与文本搜索足够 |
| OpenAI Skills 目录 | 不批量安装 | 已有所需系统技能，只按需检查安装 |

原仓库：
- https://github.com/github/github-mcp-server
- https://github.com/upstash/context7
- https://github.com/microsoft/playwright-mcp
- https://github.com/oraios/serena
- https://github.com/openai/skills

没有新增收费服务。验收使用现有模型额度；未来第三方价格、额度与认证要求需当时核实。本机校验曾使用隔离目录下 PyYAML 6.0.3 运行 Skill Creator 的 quick_validate.py；此依赖不是本 Skill 运行前提。
